# Personal Expense Tracker

A simple and interactive Command-Line Interface (CLI) application built in Python to track and manage personal expenses.

## Features
- **Add Expense**: Record new expenses with title, amount, category, and date.
- **View Expenses**: Display all recorded expenses.
- **Search by Category**: Easily find expenses filtered by their category.
- **Calculate Total**: Get the total amount spent.
- **Monthly Summary**: View expenses and total spendings for a specific month.
- **Delete Expense**: Remove any incorrect or old expense entries.
- **Persistent Data**: Automatically saves and loads data using a CSV file (`expenses.csv`).

## Technologies Used
- Python 3
- CSV Module (Built-in)
